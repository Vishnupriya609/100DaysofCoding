# Print Statements
## print() statements are used in programming to display output to the console or terminal.Output color supports *Red,Black*
## Differences between the System.out.println() & System.err.println().

| Feature | System.out.println  | System.err.println        |
| ------- | ------------------- | ------------------------- |
| Stream  | Standard output     | Standard error            |
| Purpose | Normal messages     | Error messages            |
| Color   | Usually white/black | Often red (IDE dependent) |
| Order   | Buffered            | May print immediately     |

## Common Uses
- Debugging code
- Showing program results
- Tracking variable values
- Logging execution flow
## In Java, we use System.out.println() or System.out.print() to display output.
🔹 1. print() : Prints output in the same line

🔹 2. println() : Prints output and moves to next line

🔹 3. printf() : Used for formatted output
