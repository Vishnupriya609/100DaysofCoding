# Data types in java
## what is data type?
### Data type is a classification of data which tells compiler or interpreter how the programmer intends to use the data.

### Types are
- primitive data types : Store simple values directly in memory.
- Non - primitive data types : Store memory references to objects.

## Computer memory units
- bit - binary digit
- Nibble - 4 bits
- byte  - 8 bits
- Kilobyte - 1024 bytes
- Megabyte - 1024 kb
- Giga byte - 1024 mb  (Ram & Storage)
- Terabyte - 1024 gb (Hard disk)
- petabyte - 1024 tb (Data centres)
