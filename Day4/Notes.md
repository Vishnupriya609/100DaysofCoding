 Eclipse is IDE , a free,open-source used by developers to write,debug,compile the code in one software.

## Getting started with Eclipse IDE
###  What is Workspace?

 workspace is a physical directory on your computer that acts as a logical container for your development environment.It serves two primary functions : Orgainizing a set of related projects & storing your specific configuration & preference settings .we can create multiple workspaces.
### Understand some of the important sections & options in Eclipse IDE
- Menu control options
- shortcut menu bars
- pacakge Explorer or project Explorer
- Console 
- Work Area
  
 If you close any section then Click window option in UI  Window ---> Show view

## Writing & executing our java program using EClipse IDE
### what is project?How to create a project?

 Project is container for storing & creating files for application
 
- Go to File option
- create java project with project Name,choose the java version for execution environment.create project layout choose one click Next
- create folder with Jre System library & src files we can add your system java version for targetting compilation,packages,classes and features
- write  java program & click run as + java application shows output in console.
- class files created in bin
- for main method ----> main + ctrl + space
- for  println method -----> Sysout + ctrl + space
