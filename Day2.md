## Understand the terms LTS and Non-LTS
### In Java, LTS and Non-LTS refer to how long a Java version gets support and updates.
### LTS (Long-Term Support)
- Supported for many years
- More stable for real projects and companies
- Best for learning + development
- Gets security updates for a long time
### Popular LTS versions
- Java 8
- Java 11
- Java 17
- Java 21 (latest LTS)
### Non-LTS
- Supported only for a short time (about 6 months)
- Mainly for testing new features
- Not commonly used in companies for long-term projects
### Examples
- Java 9
- Java 10
- Java 12
- Java 13
- Java 14
- Java 15
- Java 16 and so on
